# AGENTS.md — AI Usage Tracker

Guidance for AI coding agents working in `Z:\Application\ai_tracker`.

## Overview

**AI Tracker** (`ai-usage-tracker`) is an Electron + TypeScript + React + Vite Windows desktop widget and system tray app that monitors usage, rolling quotas, reset countdowns, and estimated costs across **multiple accounts** for four AI coding tools:

1. **Claude Code** (`claude-code`)
2. **Antigravity** (`antigravity`)
3. **Gemini** (`gemini`)
4. **Codex** (`codex`)

## Commands (Windows PowerShell Important Note)

> **CRITICAL:**
> 1. On this Windows system, PowerShell script execution policy blocks `.ps1` wrappers such as `npm.ps1` and `npx.ps1`. **Always invoke `npm.cmd` and `npx.cmd`** from PowerShell (or run inside `cmd /c`).
> 2. `npm` v11+ gates postinstall scripts via `allowScripts`. If `esbuild` or `electron` binaries were not unpacked during install, run `node node_modules/esbuild/install.js` and `node node_modules/electron/install.js`.
> 3. When running from a mapped network/SMB drive (`Z:\`), Windows AppContainer rejects sandboxed Electron binaries on remote shares (`install_dir_access.cc:52`). Always launch via `npm.cmd start` or `npm.cmd run dev` (`scripts/launch-electron.mjs` stages Electron cleanly into `%LOCALAPPDATA%\ai-tracker-runtime` while keeping `sandbox: true` enabled).

```powershell
# Install dependencies
npm.cmd install

# Type-check all TypeScript (main, preload, renderer, shared, tests)
npm.cmd run typecheck

# Run full Vitest unit test suite
npm.cmd test

# Build icons + main/preload bundles + Vite renderer
npm.cmd run build

# Development mode (Vite HMR + Electron)
npm.cmd run dev

# Production run (uses scripts/launch-electron.mjs)
npm.cmd start

# End-to-end Electron smoke verification (headless-safe, temp userData, prints [SMOKE_OK])
npm.cmd run smoke
```

## Architecture & Provider Conventions

### Provider Adapter Contract
Every provider implements `UsageProviderAdapter` in `src/main/providers/base.ts`:
- `readonly provider: ProviderId`
- `collect(account: AccountConfig, ctx: ProviderContext): Promise<AccountUsageSnapshot>`

Shared building blocks you MUST reuse rather than reimplementing:
- `FileParseCache<T>`: caches parsed file summaries by `(mtimeMs, size)` so polling skips unchanged logs.
- `RateLimitGuard`: enforces a minimum 5-minute cooldown between live remote API calls per account and exponential backoff (`5m -> 15m -> 30m -> 60m`) on HTTP `429`.
- `resolveQuotas(...)`: resolves quota priority consistently (`Live API -> Active Manual/Pasted Snapshot -> Local Rolling Cap Estimate`).

### Adding a New Provider
1. Add the provider literal to `ProviderId`, `PROVIDER_ORDER`, and `PROVIDER_META` in `src/shared/types.ts`.
2. Implement `UsageProviderAdapter` in `src/main/providers/<newProvider>.ts`.
3. Register the adapter in `UsageAggregator` inside `src/main/aggregator.ts`.
4. Add profile discovery rules in `src/main/discovery.ts` and sample `/usage` snippet in `src/renderer/components/SnapshotModal.tsx`.
5. Write unit tests under `tests/<newProvider>.test.ts` using temporary fixture directories.

## Security, Privacy & Reliability Invariants

1. **Read-Only Local Inspection**: Never modify, delete, or lock files inside `~/.claude*`, `~/.codex*`, or `~/.gemini*`.
2. **Zero Native SQLite Addons**: Use `sql.js` (pure WASM). Always read SQLite files into memory via `fs.promises.readFile(...)` into `Uint8Array` before constructing `new SQL.Database(bytes)`, and always call `db.close()` in a `finally` block. Never install `better-sqlite3` or other `node-gyp` native modules unless explicitly required.
3. **Secret Isolation**: Optional tokens/API keys entered by users are encrypted via Electron `safeStorage` (Windows DPAPI) in `%APPDATA%\ai-tracker\ai-tracker-secrets.json`. Never commit credentials, never log tokens, and ensure `exportSanitizedJson()` strips secrets.
4. **Opt-In Live Sync & Polite Polling**: `liveSyncEnabled` defaults to `false` for auto-discovered accounts. All remote quota calls must pass through `RateLimitGuard` and accept `ctx.fetchFn` for deterministic offline testing.
5. **No Undocumented Host Probing**: Never scan local ports or probe undocumented local host RPC servers (e.g., Antigravity language server internal ports).
6. **Sandboxed Renderer**: Keep `contextIsolation: true`, `nodeIntegration: false`, and `sandbox: true` in `WindowManager`. Expose new IPC methods exclusively through `src/main/ipc.ts`, `src/preload/index.ts`, and `AiTrackerApi` in `src/shared/types.ts`.

## UI Invariants

- The window is frameless (`frame: false`): interactive controls inside or adjacent to `.titlebar` must carry the `.no-drag` CSS class (`-webkit-app-region: no-drag`).
- Keep `base: './'` in `vite.config.ts` so Electron `loadFile('dist/index.html')` resolves asset paths properly.
- Use `.tabular` (`font-variant-numeric: tabular-nums`) for all percentages, token counts, costs, and countdown timers to avoid jitter during 1-second timer ticks.
